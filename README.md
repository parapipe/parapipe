# เปิดเว็บทดลอง HTTPS ฟรีด้วย Render

ไฟล์ `render.yaml` เตรียมการตั้งค่าแล้ว แต่ยังไม่ได้สร้างบริการหรือเปิด URL จริง
ต้องมีบัญชี Render และให้ Render อ่าน repository ที่มีโค้ดชุดนี้ก่อน
การ Publish สภาพแวดล้อม Codex ไม่ได้ส่งไฟล์ขึ้น GitHub หรือ deploy ให้ Render

## ขั้นตอน

1. นำไฟล์โปรเจกต์ รวม `app.py`, `static/` และ `render.yaml` ขึ้น repository GitHub ที่คุณควบคุม ไม่รวม `.env`, `data/`, ฐานข้อมูล หรือรหัสผ่าน ใช้โค้ดเวอร์ชันนี้ ไม่ใช่ README ว่างใน main เดิม
2. เข้าบัญชีที่ https://dashboard.render.com แล้วเลือก **New → Blueprint** เชื่อม GitHub และเลือก repository/branch ที่มีโค้ดนี้ เลือกใช้ไฟล์ `render.yaml`
3. ตรวจว่าเป็น **Free** ก่อนสร้างบริการ ไม่ต้องซื้อโดเมน หากแพ็กเกจฟรีไม่เปิดให้บัญชีนี้ ให้หยุดและตรวจเงื่อนไขกับผู้ให้บริการก่อน
4. หลัง deploy สำเร็จ Render จะแสดง URL HTTPS ของบริการ ใช้ URL ที่ Render แสดงจริง เปิดจากมือถือได้ ใบรับรอง TLS และการ redirect จาก HTTP จัดการโดย Render
5. เข้าเมนู Environment ของบริการเพื่อดูค่า `ADMIN_PASSWORD` ที่ Render สุ่มให้ เก็บเป็นความลับ แล้วเข้าสู่เว็บด้วยชื่อ `admin` และรหัสนั้น ไม่ใช้รหัสผ่านของบัญชี Render
6. ค่า `NAIL_EARLY_DATE=2026-10-30` ยังเป็นสมมติฐานวันที่เริ่ม 07:00 ปรับให้ตรงปฏิทินร้านจริง

HTTPS จบที่ระบบของ Render แอปจะรับ HTTP ภายในที่พอร์ตจากตัวแปร `PORT` ของ Render ห้ามใส่ใบรับรองที่สร้างเองหรือปิดการตรวจ TLS เพื่อแก้ปัญหาการเปิดเว็บ
Blueprint ปิด auto deploy ไว้ เพื่อไม่เผยแพร่ทุกครั้งที่มีการ push โค้ด

## ตรวจหลังเปิดบริการ

- เปิด URL HTTPS ที่ Render ให้: ต้องถูกถามชื่อผู้ใช้/รหัสผ่านก่อนเข้าหน้าแอดมิน
- เปิด `/healthz`: ต้องตอบ `{"status":"ok"}` โดยไม่มีข้อมูลลูกค้า
- หลัง login ต้องมีแถบแจ้งว่าเป็นเว็บทดลองและข้อมูลอาจหาย
- ทดลองจองด้วยชื่อสมมติ เปลี่ยนสถานะ และลองจองช่วงเดียวกันซ้ำเพื่อยืนยันว่าถูกปฏิเสธ
- อย่าใช้คำสั่ง `curl -k` หรือปิดการตรวจใบรับรองระหว่างทดสอบ

## ข้อจำกัดของเว็บฟรีชุดนี้

**ใช้ดูหน้าเว็บและทดลองเท่านั้น ห้ามใช้เป็นสมุดคิวจริงเพียงแห่งเดียว**
SQLite อยู่บนพื้นที่ชั่วคราว ข้อมูลอาจหายเมื่อบริการพักเครื่อง รีสตาร์ต หรือ deploy ใหม่ และเว็บอาจใช้เวลาปลุกเมื่อไม่มีคนใช้งาน
คำเตือนแสดงบนหน้าเว็บด้วย `QUEUE_DEMO_MODE=1` การปิดคำเตือนไม่ทำให้ข้อมูลถูกเก็บถาวร
ก่อนใช้งานจริงต้องใช้พื้นที่เก็บข้อมูลถาวรที่รองรับ SQLite หรือปรับแอปให้ใช้ฐานข้อมูลถาวรภายนอก

การทดสอบใน Codex ยืนยันเฉพาะแอปและการตั้งค่าภายใน ยังไม่ยืนยันการ deploy, ใบรับรอง หรือ URL สาธารณะจนกว่าจะเปิดและตรวจบน Render จริง
